# Quick Answer: Minimum HTML Website Requirements

## The Absolute Minimum (7 Lines!)

```html
<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>
<body>
    <h1>Hello World!</h1>
</body>
</html>
```

## What You Need:

### 1. **One File**
- Name it `index.html` (this is the standard homepage name)
- Save it anywhere on your computer

### 2. **Required Tags (in order)**
1. `<!DOCTYPE html>` - Tells browser it's HTML5
2. `<html>` - Opens the document
3. `<head>` - Info about the page (not visible)
4. `<title>` - Shows in browser tab
5. `</head>` - Closes head section
6. `<body>` - Everything visible goes here
7. `</body>` - Closes body section
8. `</html>` - Closes document

### 3. **To View It**
- Double-click the file
- OR drag it into a web browser
- OR right-click → Open With → Browser

## That's It!

Everything else (CSS, images, links, etc.) is extra features you add on top of this foundation.

## Quick Start for YOUR Art Portfolio

Replace the content inside `<body>` with:

```html
<body>
    <h1>Your Name</h1>
    <p>Artist based in [City]</p>
    
    <h2>My Work</h2>
    <img src="images/your-image.jpg" alt="Description of artwork">
    
    <h2>Projects</h2>
    <ul>
        <li>Project 1</li>
        <li>Project 2</li>
        <li>Project 3</li>
    </ul>
</body>
```
